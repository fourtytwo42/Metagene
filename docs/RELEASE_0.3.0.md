# Metagene 0.3.0 — Historic Rules Intelligence

Metagene 0.3.0 adds catalog model v9 and structural revision `rules-ir-historic-v10`. Every playable mode now carries ordered `RuleAbility` records with typed timing, source zones, costs, targets, conditions, choices, effects, quantities, tokens, counters, duration, and delayed-effect storage. The previous `AbilityProfile` remains a derived compatibility summary for saved data and the structural hot loop.

Rules IR now drives strategy-package and combo-role discovery. The catalog retains exact residual text whenever a clause cannot be represented, and the capability policy remains conservative: ordinary rules need an execution manifest, while copy, replacement, control-changing, turn-changing, and Arena-digital rules need action-scoped scenario proof.

The original Historic copy/token deck is a permanent parser regression. Tests cover Prosperous Innkeeper's Treasure and life triggers, Glasspool Mimic's copy mode, Howling Mine's untapped condition, Nightclub Bouncer's perpetual bounce, both Whirler Rogue actions, Acidic Slime without invented damage, Thassa's devotion/blink/tap rules, Quasiduplicate and Cackling Counterpart token copies and alternate-zone keywords, Parallel Lives replacement, and Mythos of Illuna copying.

The format capability audit enumerates every legal card, reports tournament-weighted executable coverage, candidate-critical coverage, and a prioritized conformance backlog. Priority combines candidate presence, field weight, criticality, semantic risk, missing engine proof, and missing AI-decision proof. Unsupported cards remain importable and exportable but keep results Provisional.

The checked-in Parallel Lives/Mythos scenarios now use action-scoped schema 2 claims with stable clause IDs and explicit AI-decision coverage. Older stored observations remain visible and legacy.
