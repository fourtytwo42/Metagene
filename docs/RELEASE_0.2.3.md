# Metagene 0.2.3 — Mechanics Truth Gate

Metagene 0.2.3 makes uncertainty explicit before the Historic Rules Intelligence expansion. Catalog model v8 records every non-reminder Oracle clause as parsed, recognized, or an exact unresolved residual. Unresolved gameplay text contributes no structural value, appears in candidate evidence, and blocks an **Improved** claim without preventing import, evolution, inspection, or export.

Capability and route schema v2 report the full funnel: Oracle accounted, structurally parsed, engine executable, scenario verified, and AI decision-covered. Forge script presence no longer self-declares execution support. Schema-v1 whole-card conformance remains inspectable but only schema-v2 action claims can verify a specific clause. High-risk copy, replacement, control, digital, and turn-changing rules require scoped scenario evidence.

Existing runs, fields, caches, conformance observations, combo rows, and training labels are preserved. Legacy resource-only combo proofs are downgraded to hypotheses and cannot guide HexDek. Training rows without the current capability-policy and Rules revision remain auditable but cannot count toward model training or the 5,000-label GPU gate.

The release adds backend audits for format Oracle accounting, eligible versus quarantined training labels, and rebuilding per-engine capability manifests. Structural revision is `oracle-truth-gate-v9`.
